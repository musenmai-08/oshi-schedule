## 権限制約

認証主体は JWT の `sub` だけから決める。URL の subscription ID は必ず当該ユーザー所有条件と組み合わせて検索し、存在有無を漏らさない。

通常APIは既存Userだけを利用し、暗黙作成しない。初回User作成はonboardingに限定する。削除墓石がある `sub` は通常APIと再onboardingを拒否し、削除APIの再開だけを許可する。
